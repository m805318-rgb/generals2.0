GitHub Pages 部署與連線狀態指南

已內建免設定 WebRTC P2P 全球連線引擎，上傳 GitHub 即可直接多人對戰

1. 已為您內建「GitHub 零設定雲端直連 (WebRTC P2P)」！

您完全不需要申請任何資料庫或設定後端金鑰！直接把這個 index.html 檔案上傳到 GitHub Repository 並開啟 Settings → Pages，任何人打開您的 GitHub 網址就能透過 4 位數房號或邀請連結即時跨國對戰！

2. 三步驟上傳到 GitHub Pages：
  1. 在 GitHub 建立一個公開 Repository（例如 generals-game）。
  2. 將本檔案儲存為 index.html 並上傳至該 Repository 根目錄。
  3. 進入 Repository 的 Settings → Pages，在 Branch 選擇 main 並點擊 Save，約 1 分鐘後即可獲得您的專屬遊戲網址！
3. 進階選配：自訂 Firebase 公開房間列表 (非必要)

預設的 P2P 引擎已支援房號與網址邀請對戰。若您未來想額外架設伺服器列表，也可在下方貼上您的 firebaseConfig JSON：
