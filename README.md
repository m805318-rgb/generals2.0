## 操作

- 點格子選取；WASD／方向鍵安排路線。道路與馬車加速需要預先排入連續路線。
- Z：50% 分兵；E：撤銷一步；Q：清空佇列；H：回主城；M：遷都。

- 選格資訊會顯示該格規則、工兵與馬車；手機版可用「排行」按鈕展開排行榜。

| 傳送門 | 成對出現，沿進入方向從配對出口外一格穿出；自身永遠無主、無兵。出口受山脈、硬邊界或循環通道阻擋時，移動不執行。 |
| 岩漿 | **無法佔領或停留**。沿移動方向穿過，每一格扣 **n=3** 兵，直到下一個可停留格。兵力可全部損失；出口受阻則整步不執行、不扣兵。這取代上一版的停留每回合扣 1 兵。 |
| 軍官營地 | B 花 **n=30** 兵招募一位同勢力軍官，營地須留下至少 1 兵。軍官每回合額外操作一次，可使用你的非主城兵力，與玩家同回合行動。**不會抽調任何己方主城，也不會把部隊匯入己方主城**；玩家已排路線的來源格優先保留。每人預設最多 3 位，可調 1–8。 |
| 瞭望台 | 初始中立 **n=20** 兵；佔領後取得方形半徑 **r=4** 的視野，每回合損耗 **k=1** 兵。兵力歸零即變回中立；不另外獲得教堂或領地增兵。 |
| 自爆哥布林營地 | B 花 **n=20** 兵，在可通行的相鄰格產生 1 位工兵；費用從營地駐軍扣除並留下 1 兵。任意勢力部隊都能帶走工兵。爆破消耗 1 工兵，把目標周圍 **n×n，預設 3×3** 的山脈改成平地；部隊留在原格。 |
| 砲台 | 初始中立 30 兵；視野與射程預設均為 **5×5 方形**。每回合向範圍內最近敵軍射出 **floor(自身兵力 × 50%)**，至少留下 1 兵。50 兵的砲台射出 25 兵並剩下 25 兵。射擊只造成傷害、不佔領目標；比例、射程及視野可調。固定射擊量預設 0，若設為大於 0，則改用固定量以相容舊玩法。 |
| 馬車 | 以小車標記顯示，是附著於格子的物件而非領土。任何人的部隊通過即可帶動。帶車的同一支部隊預設 **2 倍速**；即使戰鬥失敗，車仍留在目的地，可被後來者帶走。 |
| 賭場 | 移入的這一批兵力先擲獎，再與目的格結算。預設 **50% 歸零、47% 變成 2 倍、3% 大獎 10 倍**；既有駐軍不參與這次下注。大獎機率與倍率可調。工兵炸到賭場時會拆除賭場，附近平地散落少量兵力，無主平地上的兵需打下才取得。 |
| 道路 | 同一支部隊在道路上預設 **2 倍速**。以來源格計算本步速度；進入普通地形後停止享有道路加速。與馬車同時存在時取較高倍率，不相乘。不能利用同一支部隊的加速額度操作另一支不相連的部隊。 |

工兵、馬車以小標記疊在格子上，不取代原地形。地圖生成數量／密度是目標值；空間不足、主城通路修復等情況可能減少實際生成量。修復會保留一般陸地通路，避免主城只能穿越受阻的岩漿／傳送門才能離開。

賭場只涉及遊戲內兵力。單格兵力上限為 10 億，防止連續大獎造成整數溢位。

## 模式

**多主城**：每位玩家 1–4 座主城，全部主城被攻陷才淘汰。任何被攻陷的主城立刻變成教堂，不會因奪回而恢復為主城。失去一座主城時仍保留其餘領土；最後一座失守才依原規則轉讓領土、兵力減半。

**驟死賽**：可開關，預設門檻 10 分鐘。達到門檻後，全圖永久向所有人顯示；優先於濃霧事件，不再恢復迷霧。

**地圖邊界**：預設硬邊界。開啟「關閉硬邊界（四邊互通）」後，左右與上下互接，地圖外多一圈點擊區域。移動、傳送出口、範圍判定與遷都敵軍檢查都考慮跨界距離。

**AI 強度**：簡單每 2 回合一步；普通每回合一步；困難每回合兩步；專家每回合三步。局部戰術深度為 1／2／4／6 格。普通以上另外使用全圖路線規劃，記住視野內發現的敵方主城；攻城目標持續至失效，後方兵力沿共同路線匯集。尚未發現主城時會遠程探索，己方主城受威脅時優先回防。這仍是啟發式規劃，不是完整對局樹搜尋。

**遷都延續上一版規則**：兩地曼哈頓距離 2 格內有敵軍就禁止；成功時清空原主城駐軍，目的城市原有兵力保留。其餘主城不受影響；每局一次。隨後的正常回合增兵仍會發生。

## 隨機天災

總開關預設關閉。開啟後可分別勾選事件種類，事件間隔預設隨機 **30–90 秒**，可調最短／最長值。房主統一抽取事件，玩家端不自行抽籤。

| 事件 | 效果 |
| --- | --- |
| 地震 | 在局部區域重新分布山脈；保護已有部隊、主城與建築，必要時修復主城通路。 |
| 火山 | 以設定基準半徑的 **3 倍**生成集中山體，中心為岩漿，山腳隨機散布岩漿；避免直接覆蓋部隊與既有建築。這是線性尺度放大 3 倍，未受遮擋時作用面積約為原來的 9 倍。 |
| 放晴 | 全圖向所有人顯示，預設 **3 秒**，可調 **1–300 秒**；之後恢復當時應有視野。 |
| 隕石雨 | 預設隨機落下 **5 顆**，每顆使 **3×3** 區域兵力歸零；不拆除地形、不直接判定主城被攻陷。顆數與區域邊長可調。 |
| 迷霧 | 預設持續 **10 秒**，可調 **1–300 秒**，僅顯示目前操作的己方格附近；選到視野外或未佔領格時退回最近操作格／主城，不允許點任意遠方格偷看。放晴暫時優先，驟死永久優先。 |
| 神蹟 | 出現 **2×2** 超級教堂，預設 **200 中立兵分配到四格**（各 50），上、下、左、右各 2 座砲台，共 **8 座**。同一勢力完整佔領四格才取得全勢力教堂產兵 ×2；四格合計相當於四座教堂，完整佔領後每回合總共 +8。未完整佔領時，各已佔領格僅 +1；失去任一格即失去該組加成，多組不重複倍增。 |
| 軍閥 | 隨機出現 1–3 名獨立 AI 勢力，每名自帶 **1 主城（40 兵）＋2 教堂（各 20 兵）**。單次最大數量可調；整局累計軍閥上限預設 8，可調 0–64；不計原本玩家，空地不足則減少或略過。軍閥不會自動加入既有隊伍。超過 12 勢力時色盤循環使用，可用名稱辨認。 |

時間採實際對局經過時間，在回合邊界套用；單機暫停及單機即時回放時不計時。線上對局觀看回放不會暫停房主，關閉回放後恢復最新同步狀態。大型或背景分頁造成的延遲可能使事件於下一次回合更新時才顯示。

## 連線、回放與程式結構

- 房主掌控戰鬥、事件、軍官、賭場和軍閥生成；擴充規則同步至大廳。
- 每回合同步地形、兵力、動態玩家、工兵、馬車、水流方向、天氣及動畫。50×50 以上地圖使用差異封包，每 20 回合或大量變動時回傳完整狀態；缺少基準時自動要求完整重同步，不重啟對局。重送的已執行指令會被過濾。
- 回放快照記錄動態玩家、主城、額外物件與規則，匯出 JSON 後仍能還原。可讀取上一版沒有擴充欄位的回放。
- 畫面使用離屏快取，只有回合、鏡頭、選格或視野改變時才重畫棋盤，動畫另行疊加。AI 以距離場取代重複全圖目標排序，主城戰略路線與傳送反向邊可快取；局部戰術使用強兵力加輪巡候選，避免固定忽略同一區域。
- 回放共用未變更的水流／工兵／馬車陣列快照，減少配置與記憶體占用。地圖兵力快照及 JSON 匯出仍是完整資料，超長大地圖回放仍有記憶體成本。
- 保留上一版 RTT 顯示、可辨識建築圖示、山脈樣式和非灰色勢力色盤。

## 2.4.7 火山中心通路

每次火山生成後，建立東西、南北兩條直線道路貫穿中心並延伸到山腳外一格。沿途空地與山格轉成道路，保留岩漿、建築及所有權；岩漿依原規則可穿越並扣兵。生成位置避開通路上的傳送門，確保不會在中心通路被傳送至別處。硬邊界附近道路截至地圖邊緣，四邊互通模式可跨界。雙向穿越核心與既有回歸測試通過。
